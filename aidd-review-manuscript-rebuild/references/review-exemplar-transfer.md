# Review exemplars: observe, abstract and transfer

## Select by *review function*

Start with user-approved full-text reviews if available. Otherwise, retrieve accessible review papers compatible with the same primary genre (narrative-critical, technical survey, scoping, systematic) and nearby AIDD subdomain. Prefer alignment in argument function and methodological breadth over impact factor. A strong empirical paper is a primary *evidence source*, not automatically a strong review-writing exemplar.

A manageable initial set is 2–5 exemplars; it's not a validation threshold. Roles: (a) whole-paper intellectual architecture, (b) a comparison-heavy discussion section, (c) a taxonomy/figure/table, optionally (d) a critical perspective with balanced limitations. One paper may serve multiple roles. Confirm precise paper identity/version, actual access scope, and whether visuals were viewed.

## Three-pass inspection

**Whole-paper:** central question; argument and sections; when categories are defined; movement from description to synthesis; how limitations affect conclusions; how displayed materials relieve rather than duplicate prose. Note a weakness: journal publication is not proof a design choice is universally good.

**Paragraph clusters:** read a full relevant span with neighboring paragraphs. Code sentence/paragraph functions: evidence framing, operational definition, cross-study contrast, alternative explanation, counterexample, limitation, inference, next step. Identify topic sentences, handling of citations, link between claims, and uncertainty. Do **not** copy phrasing or formulaic five-sentence paragraphs.

**Pages and visuals:** view real rendered page(s), figure legend and neighboring text. Inspect whether categories appear as a hierarchy, orthogonal axes or overlapping roles; distinguish empirically measured vs proposed arrows; test readability at journal column width; identify table notes essential to interpreting source differences. A caption-only reading cannot verify layout.

## Transfer-card template

```text
ID: EX-01
Source: [full bibliographic identity + version + local path/URL]
Inspected: [full main text / exact section and adjacent paragraphs / rendered page and caption]
Genre/function match: [why appropriate, and mismatch]
Observed choice: [concrete, locatable rhetoric or visual organization]
Why it helps the reader: [inference, distinguished from source observation]
Transfer condition: [what this review must actually have to use it]
Reject / do not copy: [distinctive expressions, incompatible claims, unsupported visual elements]
Apply to: [target section, paragraph, figure, or table ID]
Verification question: [observable effect in revised output]
```

**Good observed choice:** “The comparison section defines a single causal question before juxtaposing different architectures; the table notes that benchmark protocols differ, so the conclusion is about mechanism rather than reported absolute scores.”

**Bad observed choice:** “Uses Nature style and superior academic English.”

## Example transfers by rhetorical job

- **Introduction gap:** move from field breadth to a precise unresolved *comparison question* instead of repeating “AI is transforming drug discovery.”
- **Taxonomy:** define roles operationally and use a second orthogonal dimension when subclasses overlap.
- **Methods comparison:** pair an implementation diagram with a table of conditions; separate source-documented mechanics from review inference.
- **Critical synthesis:** present convergent evidence, then identify a discordant protocol/result and its interpretive consequences.
- **Outlook:** pose a falsifiable test with controlled splits/data, rather than “larger datasets and better models are needed.”

Never import a source's original figure, distinctive page composition or exact phrase. Rebuild independently from the user's substantiated evidence. No article is permission to invent missing literature or claim evidence stronger than the source.

## Transfer contract and pilot check

Select 4–8 consequential decisions (fewer for scoped tasks). Map each to specific manuscript/figure outputs and identify one exemplar practice deliberately **not** transferred. Then compare **same-function** originals and revised outputs. Don't assess fidelity by lexical similarity. A different topic or evidence base makes aesthetic imitation a weak test; verify local reader function, not paper identity.
