# 从头写作输入单（可选；不要求填写完整）

这张表可以由 Codex 根据已有文件代填。没有的材料写“未提供”，不必先补成一篇中文论文。

## 写作请求
- 模式：完整初稿 / 仅校准小样 / 仅大纲 / 指定章节。
- 一两句话说明研究在做什么：
- 希望读者最后记住什么（这是意图，不等于已证明的结论）：
- 正文语言：默认英文；分析说明：默认中文。
- 投稿对象、年份、track/文章类型：未确定也可以。
- 输出格式：Markdown / LaTeX / 其他明确格式。

## 可用输入（给出实际路径或直接提供内容）
- 中文笔稿、零散记录、口头式意图说明：
- 实验结果表、日志、逐样本预测：
- 已有图片、图注、作图数据和源文件：
- 方法说明、代码、实际训练配置（可选）：
- 喜欢的参考论文及希望借鉴的位置（可选）：
- 已知失败、负结果、尚未完成的实验：
- 必须保留的术语、观点或表述偏好：

## 允许范围
- 默认允许阅读已提供材料、撰写新稿、重组原有图表和改写图注。
- 从已有数据重新汇总或重绘：允许 / 不允许 / 仅以下范围。
- 新增事后诊断分析：默认不执行，除非明确授权。
- 重新训练、修改划分或标签、补跑实验：默认不执行。
- 使用外部服务或上传未发表材料：默认不允许。
- 输出目录：默认建立新的版本化目录，不覆盖原始文件。
