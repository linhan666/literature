# Candidate Orthogonality Check

Two ideas should be merged when their central scientific claims are effectively the same.

## Compare these dimensions

| Dimension | Question |
|---|---|
| Bottleneck | Are they solving the same causal bottleneck? |
| Causal claim | Do they make the same claim about why the intervention works? |
| Decision locus | Is the same decision being automated or improved? |
| Evidence logic | Do they consume essentially the same evidence for the same reason? |
| Evaluation logic | Would the same experiment validate both? |
| Contribution | Would success create the same new knowledge/capability? |

## Superficial differences that do NOT establish orthogonality

- replacing one model architecture with another;
- using a different dataset of the same role;
- changing software package or tool vendor;
- changing target class without altering the scientific question;
- renaming workflow stages;
- adding an LLM interface to a static pipeline.

## Strong evidence of orthogonality

Ideas are genuinely distinct when at least one of the following changes substantially:

- the scientific question;
- the causal bottleneck;
- the hypothesis;
- the autonomous decision being studied;
- the type of evidence required;
- the validation logic;
- the form of scientific contribution.
