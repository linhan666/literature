# Editorial scientific review slide system

**Editorial-Light**: warm off-white background `F9FAF8`, ink navy `183044`, title dark `183044`, muted `617482`, teal `087E83` for key concept, ochre `C58C3B` for contrast/conditions, lavender `786C9F` for orthogonal/secondary lens, warning red `A65B5C`, surface white and cool border `DAE5E7`. Color is semantic and consistent. Avoid green=verified, red=wrong shortcuts for contested literature.

16:9 (13.333 × 7.5 in). Left/right >=0.64in; content top >=1.82, footer at 7.10; grid gap 0.20–0.28. Title ~29–33pt; panel headings 19–22; body 15–19; body in dense matrices 12.5–15 with <=7 rows; source footer >=10. One main claim per slide, negative space preserved. Chinese: Microsoft YaHei/Noto Sans CJK SC fallback; English: Aptos/Arial. Do not abuse `fit-to-shape` to hide overflowing text; shorten/refactor before decreasing below readability thresholds.

**Visual rhythm**: dark editorial cover + mostly light analysis pages + occasional light-tinted thesis slide + dark close. Separate visual roles: taxonomy ~ clustered blocks; mechanism ~ flow; comparability ~ decision grammar; evidence ~ map; timeline ~ stacked tracks; agenda ~ priority paths. Don't use the same grid for all content pages.

**Source style**: compact lower-left source keys, full source in slide notes/appendix. Use an episteme tag near the top: `SOURCE-REPORTED`, `AUTHOR-PROPOSED`, `INFERENCE`, `DISPUTED`, `UNRESOLVED`, `DEMO`. Tables not giant screenshots. All routine shapes and text editable. External images retain unmodified scientific content and should have original metadata.

**Hard avoids**: paper screenshot collage, default PowerPoint bullets, unscaled bibliography walls, generic stock molecules, neon gradients, unreadable axes, random arrows, unlabeled metrics, chronology-as-inheritance, made-up numeric benchmarks or paper counts.
