# Codex 启动指令：科研实验结果 → 高质量 PPT

请在 Codex 中打开你的实验项目，将以下 Prompt 作为启动指令（按真实目录替换路径）：

```text
$scientific-presentation-designer

任务：从本项目的实验结果与实验报告中构建一份专业、清晰且美观的科研 PPT，目标是 12 分钟中文组会汇报，约 10–12 页。

输入（先探测真实存在的文件，不得假设）：
- 实验报告：./report.md 或项目内其他已完成报告；
- 原始实验结果：./results/ 内 CSV/JSON/日志；
- 原始科研图：./figures/ 内真实的结构图、训练曲线、ROC/PR 图、消融图；
- 方法与实验配置：项目源码、配置文件及 README。

流程要求：
1. 先汇总源文件、核对结果和实验设置，建立 evidence_ledger.csv，并列出所有冲突/缺失；
2. 依据听众和报告时长构建 slide_plan.json。按“研究问题 → 方法 → 评估协议 → 核心结果 → 消融/稳健性 → 局限 → 下一步”组织，不要机械复述 Markdown 目录；
3. 采用 16:9、白底、藏蓝+青绿强调色、明确对齐网格、强信息层级。每页只讲一个核心判断，用足够大的标题、图表、关键数字；
4. 用可编辑 PPT 图形绘制流程、结果对比和简单统计图。原始科学结构图、化学结构与复杂模型图使用真实来源，不可凭空重绘改变含义；
5. 不得编造数据、统计显著性、错误线、置信区间、基线或引用。所有测量值精确对应源文件；
6. 输出 PPTX 后必须渲染所有页面为 PNG，查看联系表与每页大图，修改文字重叠、过小字体、难读图例、颜色不一致、图表拥挤等问题。反复修正直至没有明显的视觉缺陷；
7. 最终交付 presentation/research_deck.pptx、slide_plan.json、evidence_ledger.csv、逐页预览、qa_report.json、presentation_notes.md。明确所有仍需人工核实的科学问题。

不要在完成一个排版粗糙的 PPT 后就停止；“幻灯片可读、可讲、好看且数据可信”才是完成标准。
```

设计方案及各类汇报情形的变体见 `references/codex_prompts.md`。
